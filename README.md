# Simple Platformer Game

A basic platformer game built with Phaser 3.

## Features
- Player movement and jumping physics
- Collectible coins with animations
- Score tracking
- Platform obstacles

## How to Run

### Option 1: Run locally with a simple HTTP server
1. Clone or download this repository
2. Navigate to the project directory in your terminal
3. Start a simple HTTP server:
   - With Python 3: `python -m http.server`
   - With Node.js: `npx serve`
   - Or use any other HTTP server tool you prefer
4. Open your browser and navigate to `http://localhost:8000` (or whichever port your server uses)

### Option 2: Just open the HTML file
In some browsers, you can simply open the `index.html` file directly in your browser. However, this might not work properly due to cross-origin request policies with some browsers.

## Controls
- Left/Right Arrow Keys: Move the player
- Up Arrow Key: Jump

## Game Objective
Collect all the coins to increase your score!
